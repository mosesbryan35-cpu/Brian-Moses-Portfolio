# Brian Mokua Moses — Portfolio

A lightweight editorial/documentary portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual design
- `script.js` — navigation and project case-study interactions

## Replace placeholders
Search `image-placeholder` in `index.html`. Replace each placeholder block with an `<img>` using your own photography.

Example:
```html
<div class="project-image">
  <img src="assets/adventure-go.jpg" alt="Brian documenting a field project with Adventure Go Kenya">
</div>
```

Do not present placeholder images as real work.

## Add real professional links
In `index.html`, replace the `#` values for LinkedIn, Instagram and YouTube once the real URLs are available.

## Add video
Replace the video placeholder cards with real YouTube/Vimeo embeds or linked thumbnails.

## CV
Add your final CV as:
`Brian_Mokua_Moses_CV.pdf`
and add a real download button/link once the file is ready.

## Publishing
This is a static website. It can be published on GitHub Pages, Netlify, Vercel or any standard static host without a paid API, CMS or backend.

No contact form is faked: email and phone are provided as reliable contact methods.
